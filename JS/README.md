# Beginner JavaScript Projects

This folder contains four simple beginner projects:

1. `01-light-toggle-image` - turns a light on and off by changing an image.
2. `02-age-checker` - checks if a user is an adult or not.
3. `03-light-dark-mode` - switches a page between light mode and dark mode.
4. `04-simple-bank` - deposits and withdraws money from a simple bank account.

Open each project's `index.html` file in a browser to run it.
